# Event-Driven Order Processing System

A lightweight Python application demonstrating Event-Driven Programming (EDP) with a local event queue, event producers, and event handlers.

## Requirements
- Python 3.x (no external libraries required)

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/muhsinarsu35749/edp-order-system.git
cd edp-order-system
```
2. Run the application:
```bash
python app.py
```
